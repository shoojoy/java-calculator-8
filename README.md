# java-calculator-precourse

프리코스 1주차 미션: 문자열 덧셈 계산기

## 기능 목록

- [x] 시작 문구 출력: `덧셈할 문자열을 입력해 주세요.`
- [x] 입력 한 줄 읽기: `Console.readLine()`
- [ ] 빈 문자열이면 `0` 반환
- [ ] 기본 구분자(`,`/`:`)로 분리 후 합산
- [ ] 커스텀 구분자(`//<d>\n`) 지원
- [ ] 토큰 → 정수 변환 (공백 제거)
- [ ] 음수/비숫자/빈 토큰 등 예외 상황 처리 → `IllegalArgumentException`
- [ ] 결과 출력: `결과 : <합>`
- [ ] 입출력(`Application`)과 계산로직(`StringCalculator`) 분리
- [ ] 경계 케이스 정리/테스트: `""`, `"1,2:3"`, `"//;\n1;2;3"`, `"1,,2"`, `"1,-2"`, `"1,a"` 등
